Comment modifier le site, pas à pas

Guide pour les membres du bureau - aucune connaissance technique requise

1

🔑Se connecter

Ouvrez la page www.asa-prenois-bourgogne.org/admin puis cliquez sur le bouton « Sign in with GitHub » (se connecter avec GitHub).

Saisissez votre identifiant et votre mot de passe GitHub si la page vous les demande. C'est le compte qui vous a été créé lors de votre arrivée comme éditeur.

2

📚Choisir une rubrique

Dans le menu de gauche, cliquez sur ce que vous voulez modifier : Actualités, Meetings (calendrier), Journal Run Essence, Pages du site, Contact...

Chaque rubrique affiche une courte explication de ce qu'elle contient. Cliquez ensuite sur l'élément à ouvrir.

3

✏️Modifier le texte

Changez simplement le texte dans les cases. Sous chaque case, une petite phrase explique à quoi elle sert.

Vous ne pouvez rien casser : tant que vous n'avez pas enregistré, rien n'est publié. En cas de doute, fermez la page sans enregistrer.

4

📷Ajouter une photo

Cliquez sur la case photo, puis sur « Choisir un fichier », et sélectionnez l'image sur votre ordinateur.

Toutes les photos du site sont aussi visibles dans l'onglet « Assets » (la photothèque), où vous pouvez en ajouter ou en supprimer.

5

✅Publier

Cliquez sur le bouton « Save » (enregistrer) en haut de la page, puis sur « Publish » (publier) si le bouton apparaît.

Patientez 1 à 2 minutes : le site public se met à jour tout seul. Ouvrez le site et actualisez la page (touche F5) pour voir votre modification.

En cas de problème

Impossible de se connecter ? Vérifiez que vous avez bien accepté l'invitation reçue par email lors de la création de votre accès.

La modification n'apparaît pas ? Attendez 2 minutes puis actualisez la page du site (touche F5).

Un doute ? Ne supprimez rien et contactez l'administrateur du site. Toutes les modifications sont récupérables, rien n'est jamais perdu définitivement.
